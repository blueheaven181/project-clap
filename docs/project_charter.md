# Project CLAP Charter

## Purpose

Project CLAP is a local-first personal desktop assistant and a practical
software-engineering learning project. It combines voice interaction, trusted
automation, live information, desktop control, and local AI while keeping Marc
in control of every consequential action.

## Current Objective

Maintain a dependable Windows assistant that activates through a double clap or
“Hey CLAP,” answers trusted commands, provides a controllable daily briefing,
reads Google Calendar information, and creates Calendar events only after
confirmation.

## In Scope

- Voice activation and speech interaction
- Weather, system health, forex, conversion, and live news
- Google Calendar schedule, availability, and confirmed event creation
- Trading workspace, Spotify, and Windows volume automation
- Local Ollama conversation and coaching
- Security, documentation, testing, and reproducible setup

## Out of Scope for the Current Milestone

- Arbitrary commands generated by the conversational AI
- Unconfirmed external writes or sensitive actions
- Google Tasks, smart-home devices, packaging, and mobile access until their
  planned sprints begin

## Success Criteria

- Existing trusted commands continue to work after each increment.
- Calendar events preserve Abu Dhabi time and require confirmation.
- Credentials and private configuration remain excluded from Git.
- Speech can be safely stopped and CLAP returns to standby.
- Affected Python files compile and automated regression tests pass.
- Documentation reflects the repository's current behavior.

## Guiding Principles

- Develop in small, testable increments.
- Prefer local processing where practical.
- Use least-privilege access for external services.
- Keep automation deterministic and separate from general conversation.
- Preserve a safe manual exit with `Ctrl+C`.
