# Articulation Training

## Purpose

CLAP's articulation mode helps Marc express professional ideas clearly,
concisely, and with a recognizable structure. It complements general
conversation mode with a repeatable exercise and a narrow feedback format.

## Starting a Session

Use commands such as:

```text
Start articulation training
Start communication practice
Practice my speaking
Help me improve my articulation
Train my communication
```

CLAP presents one prompt, records the answer, and sends the transcript to the
local Ollama model for coaching. A mode can be selected in the starting command.

## Exercise Modes

Three selectable modes are available:

- Work update: completed work, a problem, and the next action
- Technical explanation: problem, impact, and next action for a non-technical
  listener
- Achievement story: situation, action, and result

Example commands:

```text
Practice a work update
Practice a technical explanation
Practice an achievement story
```

If no mode is named, CLAP starts the work-update exercise.

## Feedback Format

Each response begins with five scores from 1 to 5, where a higher score is
better:

1. Clarity
2. Conciseness
3. Structure
4. Filler words
5. Confidence based on transcript wording only

The filler-word score uses the recognized transcript count: 5 means zero
fillers, 4 means one, 3 means two, 2 means three or four, and 1 means five or
more. Confidence does not claim to measure vocal tone because the coach receives
text rather than audio.

The scorecard is followed by four short spoken parts:

1. One strength
2. The single most important improvement
3. A clearer version based only on the original answer
4. One short encouragement

CLAP then asks whether the answer should be attempted one more time. Saying
`no` ends the session and returns to standby.

## Initial Exercises

- Give a work update using completed work, a problem, and the next action.
- Explain a technical issue using problem, impact, and next action.
- Describe an achievement using situation, action, and result.

The work-update exercise remains the default. Scores and transcripts are not
saved as progress data.

## Automated Tests

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_articulation_coach -v
```

Tests cover intent recognition and common speech-recognition variants, exclusion
of unrelated practice requests, exercise selection, filler counting,
feedback-prompt construction, trusted-command routing, and sessions with and
without a selected mode.

## Privacy and Boundaries

- Speech recognition still uses Google's online recognition service.
- Coaching responses are generated by the local Ollama model.
- The coach must not invent career history or personal facts.
- Training transcripts and scores are not written to a progress file.
- Console logging confirms receipt of an answer without printing its transcript.
- General coaching is not authorization for CLAP to execute an action.
